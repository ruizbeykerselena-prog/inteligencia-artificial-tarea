HEURISTICA
Definición:
Es una función que permite estimar la distancia o costo desde un punto hasta el objetivo, ayudando a encontrar soluciones más rápidas sin necesidad de calcular todo exactamente.

TEORIA DE JUEGOS 
Definición:
Es una disciplina que estudia cómo diferentes jugadores toman decisiones estratégicas cuando el resultado depende de las acciones de todos.

ALGORITMO DE A*
Definición:
Es un algoritmo de búsqueda que encuentra el camino más corto combinando el costo real recorrido y una estimación del costo restante.
