Tema1: Algoritmo A*
Definición
El algoritmo A* es un método de búsqueda que encuentra el camino más corto usando:
f(n) = g(n) + h(n)

Tema 2: Heurística
Definición
Una heurística es una función que permite estimar la distancia o el costo desde un nodo hasta el objetivo. No da un valor exacto, pero ayuda a tomar decisiones más rápidas en los algoritmos de búsqueda.

Tema 3: Teoría de Juegos
Definición
La teoría de juegos estudia cómo diferentes participantes toman decisiones estratégicas cuando el resultado depende de todos.
